# Astro Analytics Repository Guidance

This repository owns the reusable CodeWorksLabs
`@codeworkslabs/astro-analytics` product.

There is no supervisory or top Boss implied by this file. Product, Astro,
Code, Manual, Infrastructure, Server, entity, and site authorities retain
their accepted lanes and coordinate as peers. Cross-lane coordination does not
implicitly authorize writes, credentials, commits, pushes, deployment,
publication, provider actions, or other mutations.

Keep reusable package source here. Keep site implementations under
`C:\CodeProjects\Sites`, Astro operating doctrine under
`C:\CodeProjects\Platforms\Astro`, and entity-specific product decisions with
the owning product/entity lane.

Use `main`. Do not store passwords, API keys, tokens, credentials, private
account values, or production secrets. When using historical material, label
it as historical, give its source/date when known, and say whether its claims
were freshly verified.
